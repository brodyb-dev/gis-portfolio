# Map label fonts

Noto Sans Regular, Italic and Medium as MapLibre glyph files (signed-distance-field PBFs), for
the Latin ranges 0-255, 256-511 and 8192-8447 (dashes and quotes). Downloaded from
https://github.com/protomaps/basemaps-assets (`fonts/`).
